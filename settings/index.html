Reachy Voice Control & Weather — Setup

Everything else in this app works without setup — just pair your robot. This page is only for the advanced feature that lets you talk to Reachy to control your home and ask the weather.

The easy, SSH-free way is the Homey Companion app for Reachy Mini: install it from your robot's dashboard (Pollen / Hugging Face app store), then connect it to this Homey using the two values below. (The old SSH method still works if you prefer it — see the note at the bottom.)

Step 1 — Create a Homey API key

Open my.homey.app → Settings → API Keys → Create (allow device & flow access), then copy it. You'll paste it into the companion app.

Step 3 — Connect in the Homey Companion app

  1. On your Reachy Mini dashboard, install and open Homey Companion.
  2. Open its settings page (the gear), which is served at http://reachy-mini.local:7860/homey.
  3. Paste the Homey app URL (Step 2) and your Homey API key (Step 1), press Test connection, then Save.
  4. Restart the app on the robot. Now say things like “Reachy, turn off the living room lights” or “what's the weather?”
Advanced: manual SSH method (old way)

If you don't want to use the companion app, you can still install the two Python tools directly. SSH into the robot and place these tools in a folder, then set AUTOLOAD_EXTERNAL_TOOLS=1, REACHY_MINI_EXTERNAL_TOOLS_DIRECTORY, HOMEY_COMMAND_URL (…), HOMEY_INFO_URL (…) and HOMEY_API_TOKEN in the conversation app's .env, and restart it.
